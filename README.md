# Project Name : ParkClear

## 1. Description:

**ParkClear** is a modern, fully responsive, and visually stunning parking management platform built with React.js v19, JavaScript, and Tailwind CSS v4.

This project combines beautiful UI animations, optimized performance, and a clean user experience — designed to make parking management simple, smart, and efficient.

With a focus on code reusability, maintainability, and modern best practices, ParkClear offers a seamless experience featuring a user dashboard, smooth AOS animations, and an interactive design powered by Radix UI and Lucide React icons.

It is developed using React 19, Vite, and TailwindCSS, ensuring blazing-fast performance and smooth developer experience.

---

## 2. Used Technologies:

- React.js (v19) – Core frontend framework for dynamic UI
- JavaScript (ES6+) – For logic and interactivity
- Vite (v6) – Lightning-fast build tool for React apps
- Tailwind CSS (v4) – For modern, responsive, utility-first styling
- Radix UI – For accessible and customizable UI components
- AOS (Animate on Scroll) – To add smooth scroll-based animations
- React Router DOM (v7) – For client-side routing
- React Hook Form – For form handling and validation
- Swiper.js – For responsive sliders and carousels
- Recharts – For interactive and visually appealing charts

---

## 3. Main Features:

- Fully Responsive Design – Optimized for all devices and screen sizes
- User Dashboard – Intuitive, dynamic dashboard for users
- Beautiful Animations – Smooth transitions with AOS integration
- Reusable Components – Clean, modular, and DRY code structure
- Modern UI/UX – Built with Tailwind CSS, Radix UI, and Lucide React
- Interactive Charts – Display insights using Recharts
- OTP Input Integration – Implemented secure OTP verification design
- React Hook Form Validation – Simplified and reliable form handling
- Optimized Build Performance – Powered by Vite and React 19
- Clean, Readable Codebase – Well-documented and easy to maintain

## 6. Installation:

```bash
# Clone the repository
git clone https://github.com/towfiqislambd/park-clear

# Navigate into the project
cd park-clear

# Add an env.local file in root
.env.local = Add secret credentials

# Install dependencies
npm install

# Run the development server
npm run dev
```

---

## 7. Usage:

Run `npm run dev` to start the project locally. The app will run on
**http://localhost:3000**
